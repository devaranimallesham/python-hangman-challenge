# Python Hangman Challenge

Create a complete advanced Hangman game using ONLY Python.

Do not use JavaScript, React, Node.js, APIs, databases, or external files. Keep all game logic, words, hints, login, levels, scoring, and progress in Python.

Features

Simple Python login/signup with username and password.

Main menu: Play, Themes, Levels, Statistics, How to Play, Logout.

Add 35+ themes such as Games, Movies, Heroes, Heroines, Animals, Fruits, Countries, Sports, Cricket, Football, Cars, Bikes, Technology, Programming, Food, Cartoons, Superheroes, Villains, TV Shows, Space, Nature, Birds, Famous Places, Actors, Athletes, etc.

Create 10 main levels, from Beginner to Legend.

Each main level has 10 sub-levels, giving 100 sub-levels total.

Each theme/level/sub-level should have different predefined words and hints stored inside Python.

Difficulty must increase from Level 1 to Level 10.

Each word has exactly 6 wrong chances.

Correct guesses reveal letters; wrong guesses reduce one chance.

Repeated guesses should not reduce chances.

Use Python ASCII Hangman that progressively draws the man after every wrong guess.

Give every word a useful hint without directly revealing the answer.

Allow limited hints and reduce score when hints are used.

Add A-Z letter selection and keyboard input.

Add scoring, bonus points, best score, wins, losses, and statistics.

Unlock the next sub-level after completing the current one.

Unlock the next main level only after completing all 10 sub-levels.

Locked levels must remain inaccessible.

Add Classic, Survival, Random Theme, and Challenge modes.

Add win/lose screens, achievements, progress tracking, and level completion bonuses.

Reveal the correct word only after the player loses all 6 chances.

Add random word and random theme selection.

Make the game fun, colorful, organized, and beginner-friendly.

Use only Python concepts such as random, while, for, if/else, lists, dictionaries, functions, strings, and classes if needed.

Keep the code clean and well commented.

Include if __name__ == "__main__": main() so it runs directly in Python.
